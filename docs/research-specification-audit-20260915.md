## What was examined

For every task I read the instruction, relevant agent-visible starter/helpers, and recorded worker reads/edits or submitted artifact. I checked all 24 recorded task prompts against the present instructions, ignoring only benchmark-canary comments and surrounding whitespace. All matched. The 272 recorded top-level tool calls have paired outputs; this is trace bookkeeping, not proof of the absence of every possible information channel.

All 298 catalog-linked evidence hashes matched. Sixteen available whole-tree freeze hashes matched; the four BR-003 freezes use per-file hashes. Across the manifests, all 100 recorded instruction/environment file hashes checked here matched. Thus the audit is tied to the trialed inputs rather than a retrospectively rewritten prompt. The JSON retains exact paths, line numbers, hashes and the distinction between full-tree and per-file checks.

This is a specification audit, not a new provider-identity or complete historical-container forensic audit. The [earlier Terra provenance report](../runs/terra-pass-audit-20260914/report.html) and [focused SVG trace audit](../catalog/analyses/br003-svg-provenance-audit.md) separately address observed answer access and launch configuration. A legitimate, publicly supplied reference can weaken a discovery claim without being a forbidden private-answer read.

## Why this kept happening

The workshop correctly made contracts precise and kept verification independent, but sometimes shrank away the intended decision while constructing a compact task. Examples include giving both the derivative diagnosis and a nearly complete autograd graph, providing the required mapping plus its geometry helpers, and reducing mechanism discovery to three formulas with an already correct parameter.

The source failure can also disappear **without** a solution hint. The [BR-001 results](research-brainstorm-experiments-20260914.md) already record that the MR miniature excludes source issues such as singleton axes/duplicate planes, the ocean-inspired case removes polar/spherical geometry, and stress parsing is handled by a correct helper. These source-to-task changes are a different issue from private leakage or an overly helpful sentence.

The [previous 12-run audit](../runs/terra-pass-audit-20260914/report.html) had already identified the bundled Clipper reference and heavily scaffolded miniatures. We documented that caveat but did not turn it into an effective authoring check before later rounds. The actuator and SVG designs show the problem continuing. This is an authoring/process failure, not evidence that workers misbehaved.

Oracle-pass/nop-fail controls establish that the grader distinguishes a correct artifact from the deliberately wrong starter. They do **not** establish that finding the repair is hard, or that the benchmark still tests the source failure's conceptual crux. Likewise, an independent ground-truth implementation prevents some shared-bug errors but does not prevent the prompt from revealing the answer.

## What should change before another trial

1. **Write the intended unknown first.** State the inference or design choice the solver must make. Audit the complete solver-visible package against it, including comments, examples, installed references and service responses.
2. **Keep decision-complete contracts.** Specify units, coordinate handedness, output conventions, permitted input domain and observable acceptance behavior. Do not make a test harder by hiding conventions or requiring undocumented grader preferences.
3. **Separate contract from solution guidance.** Root-cause hints, named corrective methods, diagnostic probe sequences and candidate answer formulas should be recognized as assistance. If they are essential to a fair task, judge the difficulty of what remains after providing them.
4. **Inspect the simplest permitted solution before spending a model run.** Include obvious local edits, standard library calls, bundled reference ports, direct measurement fits and fixed-input transcription. A failing starter alone is not an adequate easy-baseline control.
5. **Choose a crux that survives a clear spec.** For anatomical QA, give vocabulary and label semantics while leaving case-specific anatomical consistency to infer. For coordinator design, grade durable-delivery properties if policy design is the target; an exact state-transition oracle instead measures contract implementation. For SVG, distinguish resampling supplied masks from inferring anatomy or deriving display geometry.
6. **Retire these passes rather than quietly hardening their snapshots.** A future revision needs a new frozen identity and explicit hypothesis. If we want to know whether hints caused a pass, use a separately authorized, predeclared comparison with equivalent acceptance semantics; do not infer that counterfactual from the present traces or shorten reasoning time.

No such comparison has been run. The observed result remains **24 completed passes, zero genuine local failures**, with the interpretation narrowed by this audit.
