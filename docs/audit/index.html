External Help & Web Search Audit
Network Forensics

Across 96 of the 100 runs, models operated in strict isolation without executing any network lookups. However, two specific runs under Sol/xhigh engaged external endpoints:

  • BR-016 N03 Aneurysm Localization: Sol invoked tools.web__run querying OpenNeuro ds003949. Finding that controls lack lesion masks, it curled the GitHub API tree, curled sub-000_ses-20110101_angio.nii.gz from AWS S3, and confirmed bit-exact array matching (diff 0.0 0.0 True). It verified the case was a negative control and answered [], short-circuiting the vision task.
  • BR-040 MRI32 Landmark Localization: Sol curled the AFIDS human protocol markdown, curled 32 reference PNGs, and installed templateflow to download the canonical MNI152 template. It registered the template via SimpleITK to perform atlas-assisted localization. Zero private patient labels were retrieved.

Cheating, Shortcuts & Verifier Integrity
Integrity Audit

Did the agents attempt to tamper with graders, read private answers, or hardcode static solutions?

  • BR-005 Clipper PolyTree (Test Clean-up vs. Cheating): Terra copied Tests/test_cpp_polytree.rs to tests/ to run integration tests. When holes5 failed, it executed rm -f /app/clipper2/tests/... before exit. Verdict: Clean workspace hygiene conforming to the deliverable contract (only delivering src/), but paired with selective reporting (claiming 392 tests passed without mentioning the 7 PolyTree failures).
  • BR-032 Real Echo (The Static Table Shortcut): Sol hardcoded interactive measurements into an internal OBSERVED dictionary. In replay testing where 68 of 72 video frames were replaced with still frames, the model still produced a 5.40 mm pulsating mesh without reading video pixels! (Corrected in BR-034 via 3D TV-L1 optical flow).
  • BR-034 (The Surface Distance Paradox): Sol achieved a mean surface distance of 1.89 mm (<3 mm gate), yet missed clinical Ejection Fraction by 23.3 percentage points (22.0% vs 45.3% true) due to systolic under-contraction, proving Euclidean surface error can mask severe clinical failure.

Verdict: Zero instances of direct grader tampering or reward hacking across all 100 sessions.

Efficiency & Reasoning Scaling
Performance Economics

How efficiently do models allocate steps, tokens, and reasoning depth?

  • Terra/high ($0.41 avg): Fast, lean, and targeted. Formulates solutions in ~31 steps with high compilation and low-level C++ aptitude. However, prone to setting overly tight local search bounds (±9 mm in BR-021), cutting off true targets.
  • Sol/xhigh ($1.56 avg): Exhaustive, rigorous, but computationally expensive. Consistently invests 10k–20k reasoning tokens per run. Outstanding at writing custom validation checkers (e.g. 320 synthetic test cases for Clipper), but prone to context bloat on visual tasks.
  • Astra/max (Multimodal Champion): On BR-002 Score Reading, Astra achieved 96/96 events (F1 = 1.00) in 14 steps and 195s, versus Sol's 36 steps, 850s, and 1.01M tokens.
  • The 8-Patient Batch Timeout: Terra/max timed out at 1,800s on the BR-004 batch (9.79M tokens) handwriting pure-Python 3D morphology because SciPy was missing. Isolated single-case runs completed cleanly in 10–19 minutes.

Xiangqi Engine Optimization (BR-006, 008, 009)

In BR-006, profiling showed legal move generation consumed 89% of CPU. Terra bypassed Python, authoring a complete 137 KB C++17 minimax engine with Zobrist transposition tables. In BR-008, Terra ported board primitives to C, but introduced a native reference leak (PyList_New converted to tuple without decref). In BR-009, with a strict 32-epoch memory gate, Terra fixed the reference leak and added a bounded 4,096-entry move cache, achieving a 30.2% CPU reduction and just 0.145 MiB settled RSS growth.

Clipper PolyTree: Terra/high vs. Sol/xhigh

In BR-005, removing reference code caused Terra to fail on holes5 (4 roots / 1 hole vs 3 roots / 2 holes true) due to boundary-coincident edge bugs. In BR-007, Sol solved the problem cleanly without modifying engine.rs: in engine_public.rs, it built a topological planar graph reconstruction, cancelled opposite-direction edges, and verified it against 320 self-authored synthetic test cases, passing all 144 private evaluation cases.

The Case 32 Lead Failure (Kidney Extension)

A 63-voxel connected extension of kidney_left into adjacent fat/psoas muscle. Both Terra/max ($0.857, 10.2 min) and Sol/xhigh ($2.072, 12.6 min) generated axial contact sheets directly intersecting the defect at slice 94. Both models examined the slices, concluded the contour was anatomically smooth and plausible, and validated an empty report.

BR-013 A02: Pancreas Misidentified as Gallbladder

When scipy.spatial.cKDTree failed to import, Sol collapsed the 3D masks into 2D maximum ASCII text projections (p.max(ax)). Losing 3D depth, it failed to see that the compact 43 mL pancreas was nestled inside the duodenal C-loop, mislabeling it as gallbladder (9/11). Providing raw CT intensity in BR-015 C01 allowed Sol to measure 65 HU (solid tissue vs 10 HU fluid), instantly resolving the error.

BR-021: The Transform Composition Bug

An ITK error (CompositeTransform Jacobian unimplemented) caused Terra to register B-splines directly to unaligned images while applying affine transformations on top: aff(bs(x)). Combined with an overly narrow ±9 mm search box, true targets 18.9 mm away were unreachable, causing a 12.64 mm RMS failure.

BR-023: Sol Neighborhood Regression

Sol matched 150 surrounding anatomical points and fitted local affine displacement regressions. Near q04, neighboring points consistently displaced by [+3.3, +20.1, -5.1] voxels, diagnosing that raw NCC was sliding along a vessel. Sol recentered the window and converged to 1.56 mm RMS.

BR-031: Jacobian Collapse Under Optical Flow

BR-035: Segmentation Tetrahedralization

Actionable Guidance for Benchmark Evaluators

  • 1. Enforce Hermetic Network Isolation: If evaluating autonomous perception, set network: none in Harbor. Frontier agents equipped with curl or web__run will naturally locate public dataset trees, compare raw file hashes, and bypass computer-vision evaluation.
  • 2. Decouple Multi-Instance Batches into Single Trials: Batching 8 patients into one 1,800s session (as in BR-004) results in quadratic context accumulation (9.79M tokens) and memory allocation loops. Single-instance trials isolate capability signals and reduce token expenditure by 75%.
  • 3. Guard Against Surface Distance Exploitation: In deformable organs, Euclidean surface distances (≤ 3 mm) can pass even when physiological Ejection Fraction fails by 23.3 percentage points. Benchmark graders must require derivative functional metrics (volume changes, strain tensors, manifold topology).
  • 4. Execute Control Replays with Static Videos: To prevent agents from hardcoding measurements into static dictionaries (as in BR-032), test harnesses should automatically run a secondary evaluation passing identical static frames, confirming predicted motion drops to zero.
  • 5. Pre-install Standard Numerical Tooling: Omitting standard packages like scipy or imagemagick forces agents to waste hundreds of seconds handwriting crude Python DFS searches or collapsing 3D data into 2D ASCII text grids, creating artificial failure modes unrelated to domain difficulty.
