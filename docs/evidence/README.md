# Retained evidence receipts

This directory preserves concise source, freeze, control, result and review
receipts. New generated run records live with their owning experiment under
`groups/`; large payloads, raw sessions and environments stay local.

Read a receipt through the experiment or dated protocol citing it. Paths, hashes,
model conditions and labels describe the recorded observation, not a fresh audit
of availability or scientific validity. Later corrections append an observation or
scoped review; they do not rewrite these historical bytes.

Some early receipts cite retired nonmedical probes or the old catalog. Their exact
sources are indexed by repository-relative path in
[archive/manifest.json](../../archive/manifest.json); see the
[recovery guide](../../archive/README.md). A missing local run is an availability
limit, not a failed model result. Use [governance](../governance.md) for retention
and [the workflow](../workflow.md) for current collection/review commands.
