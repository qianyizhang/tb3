# Retained research rounds

The [round register](../research-rounds.md) is dated chronology. Current research
belongs to the [semantic groups](../../README.md); use `uv run med list QUERY` and
stable experiment IDs. BR-025, for example, covers different cardiac and vessel
work, so a round number is not a unique lookup key.

Protocols, results, source audits and plans in this directory retain their original
paths and bytes. Their status language and proposed next actions describe the time
of writing. New studies use `med new`, experiment TOML and protocol Markdown through
the [daily workflow](../workflow.md). They do not need another global round document.

The [main-branch cutover](../migration/README.md) absorbed the completed
BR-042 continuation. Continue to respect active experiment ownership; a historical
plan alone does not authorize another run.

Some links require ignored local runs or retired source files. Consult
[historical navigation](../archive/README.md) and [archive recovery](../../archive/README.md).
Do not rewrite frozen outcomes or regenerate old fixtures to repair those links.
