Finding an aneurysm

Can a coding agent find a bulge in a brain artery? Across three MRI scans, Sol missed one annotated finding, located another, and checked the public dataset before answering the third.

Real scans, general image tools, and one coordinate per finding.

01 / The task

Inspect the vessels. Mark each finding.

The agent received full MRI scans designed to show blood vessels (TOF-MRA), plus a tool for viewing slices. It had to return one image coordinate per aneurysm, or an empty list.

No dedicated aneurysm detector was supplied or observed. Sol used image interpretation and code it wrote during the task.

The source dataset supplies approximate reference locations. A submitted point must match one of those regions, with 1 mm tolerance. The reference regions are not exact lesion outlines.

These three selected cases show how the agent worked. They do not measure clinical accuracy or a repeatable failure rate.

03 / Takeaways

The same score can hide different methods.

Finding the right region matters.

N01’s long search still ended with an empty answer. N02 selected a useful candidate, checked it across planes, and refined its position. More inspection alone did not ensure success.

A source-assisted pass needs its own label.

N03’s dataset lookup was allowed and useful. Its passing score belongs beside that fact whenever the result is discussed.

04 / Evidence and limits

Three attempts, with the record preserved.

All three model attempts completed normally. The scans are unmodified OpenNeuro ds003949 data (CC0); original and brain-only versions were supplied. Case selection was fixed before the trials.
