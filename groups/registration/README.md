# Registration

How do image context, acquisition changes and deformation affect correspondence and pose recovery?

Keep frozen physical-error scores alongside later visual adjudication. A public-input author method is feasibility evidence, not a human benchmark.

Use `uv run med list --group registration` from the repository root. The group owns the current research entry point; original protocols and frozen evidence remain at their recorded paths.
