# RESECT point-audit method

This method prepares one frozen two-query diagnostic task from the pinned local
RESECT sample. Case labels are neutral, published paired points remain private,
and the solver gets full FLAIR/US volumes plus a generic orthogonal-view tool.

Run `check_score.py`, then `prepare.py` once. The latter refuses to overwrite an
existing task. Use native `med run` controls and preview before one diagnostic
model dispatch. Raw volumes, task images, runs and answers remain under `.local/`.
