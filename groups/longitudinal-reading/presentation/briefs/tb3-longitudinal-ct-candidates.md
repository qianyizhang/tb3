# Track CT lesions — Comprehensive candidate contract

Track CT lesions — Comprehensive candidate contract.

## Value

Tests whether a broader review inventory recovers lesions excluded by a stricter inclusion policy.

## Given

### Original data

Two full native CT volumes at different visits.

### Supplied helpers

Broad context and a deliberately permissive tumor-candidate inclusion policy; no supplied candidate locations.

### Callable tools

Each linked protocol specifies the permitted tools and execution environment.

### Reference-only material

References and permitted access follow each frozen contract. A reader-facing source or illustration is not automatically solver-visible.

## Task specification

Produce instance masks, links/events, report and one probability/reason sidecar row per candidate. Follow each protocol's coordinate, identifier and access contract.

## Expected output

Produce instance masks, links/events, report and one probability/reason sidecar row per candidate.

## Evaluation

Score detection, overlap, instance association and events separately. Preserve all reference instances and unchanged scientific endpoints; contract revisions do not establish matched causal comparisons.

## Difficulty

Candidate retrieval and malignancy confidence are separate outputs. The broader policy exceeds the malignant reference scope, so unmatched candidates are not clinically adjudicated false findings.
