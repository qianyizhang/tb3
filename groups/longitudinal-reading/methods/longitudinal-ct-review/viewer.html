02 / What the dataset actually gives us

Three kinds of ground truth

Where

Integer masks outline each lesion in 3D. Count labeled voxels × voxel volume to measure its extent.

Which one

CSV rows link lesion identities across visits. Merging is many-to-one, not ordinary one-to-one matching.

What changed

Persistent, merging, disappearing or new. These are annotation-derived events, not proof of treatment benefit.

The source folder named inputsTr contains answers: follow-up centers, cross-visit CSV fields and registration-propagated points. Do not hand that folder to the agent unchanged. Supplied masks at both visits also need independently randomized IDs.

03 / Recommended first experiment

Marked baseline targets → correspondence graph

Give

Two native CT volumes and opaque baseline target masks. Preserve geometry and visit order.

→
Ask

Find their follow-up counterparts; allow multiple baseline targets to share one counterpart. Support each link with image locations.

→
Receive

A graph of links, follow-up points or masks, event labels, measurements and a few cited views.

Concrete prompt sketch

“For each marked baseline lesion, locate its counterpart in the follow-up CT. If lesions merge, link them to the same follow-up region. Use ‘unresolved’ where correspondence or visibility cannot be established. Return native series IDs, voxel indices, RAS millimeters and evidence slices.”

Start with correspondence. Whole-volume search for new lesions is a separate extension. Do not ask for treatment response or a diagnosis in this first task.

Score follow-up localization, correspondence edges, per-event accuracy and measurement separately. Use physical coordinates, not equal slice numbers. Many-to-one events need group-aware volume accounting. Set localization tolerances after reference review; no pass threshold or executable scorer is frozen here.

04 / What the local inspection changed

Promising data, with checks still needed

Verified in downloaded files

Eight CT/mask pairs have matching shapes and affines. Selected present-lesion CSV centers are about +0.5 voxels on each axis relative to zero-based mask centroids. One baseline mask volume differs from its CSV by one voxel; the other checked volumes agree to numerical precision.

The 300 CSVs contain 2,506 UNCHANGED, 1,407 DISAPPEARING, 559 NEWLYAPPEARING and 166 MERGING rows. Merging rows are not counts of distinct merge events. There are 135 unclear-link rows and four rows in two files without an uncertainty column.

Before an agent trial

Adjudicate coverage for disappearance; hold out the defaced facial candidate; keep unclear or missing uncertainty separate from certain links. Verify the coordinate convention for every staged source and independently deduplicate merge destinations.

Freeze a small patient-held-out set only after those checks. These examples were chosen to explain events, not to estimate prevalence, difficulty or agent performance. Public training-set exposure remains possible.
