# Adapt a cavity model and measure contraction

Adapt a cavity model and measure contraction.

## Value

Tests whether initialized reconstruction preserves clinically relevant cavity measurements on another acquisition.

## Given

### Original data

Clinical B-mode sequence with calibration/timestamps.

### Supplied helpers

Initial LV cavity surface and optional earlier executable; later surfaces and functional references are withheld.

### Callable tools

Each linked protocol specifies the permitted tools and execution environment.

### Reference-only material

References and permitted access follow each frozen contract. A reader-facing source or illustration is not automatically solver-visible.

## Task specification

Produce an image-driven executable, dynamic cavity meshes, volumes/EF and bounded functional interpretation. Follow each protocol's coordinate, identifier and access contract.

## Expected output

Produce an image-driven executable, dynamic cavity meshes, volumes/EF and bounded functional interpretation.

## Evaluation

Geometry and functional measurements against source surfaces; supplied initial anatomy removes from-scratch segmentation at that phase.

## Difficulty

The initial cavity is supplied; later contraction must come from images. Cavity EF does not establish myocardial strain or disease etiology.
