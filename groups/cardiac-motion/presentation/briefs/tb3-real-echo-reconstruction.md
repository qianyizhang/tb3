# Recover a dynamic cavity from real ultrasound

Recover a dynamic cavity from real ultrasound.

## Value

Explores dynamic reconstruction from real ultrasound without a source mesh.

## Given

### Original data

Calibrated planes from a real 3D echo sequence.

### Supplied helpers

Acquisition geometry, no initial source mesh or labels; held-out planes are review-only.

### Callable tools

Each linked protocol specifies the permitted tools and execution environment.

### Reference-only material

References and permitted access follow each frozen contract. A reader-facing source or illustration is not automatically solver-visible.

## Task specification

Produce a dynamic closed LV cavity surface with shared connectivity and uncertainty. Follow each protocol's coordinate, identifier and access contract.

## Expected output

Produce a dynamic closed LV cavity surface with shared connectivity and uncertainty.

## Evaluation

Image overlays and mesh validity are diagnostics; no independent segmentation/material GT means no clinical geometry or strain accuracy claim.

## Difficulty

Image edges and plausible closed surfaces are not independent geometric truth. Depth and basal assumptions can admit several plausible completions.
