# Retained examples

The [source-linked task card](../presentation/card.json) identifies the actual input,
output, cases and measurements. [Static figures](../presentation/figures/) and the
[group story](../presentation/story.md) are portable review examples, not extra
model inputs. Exact native samples stay with their frozen task and source receipts.

Use `python3.12 scripts/med new cardiac-motion NEW-ID --title TITLE` to start
a disabled scaffold. Copy a case only after selecting its source, truth, license
and solver/evaluator boundary; do not import an old authoring module to get a sample.
