# Investigate historical task sources

Turn retained work-history leads into inspectable task contracts, then keep source claims, author controls and original model outcomes separate. BR-003 produced four passing prototypes; authentic vector-crop ownership remained untested.

## Value

Source inspection can yield useful task ideas without converting complaints, recollections or infrastructure observations into model failures.

## Given

### Original data

The retained index has 395 records. Excluding 142 automatic reviews and 16 other long-title records leaves 237 navigable records. The historical study selected nine conversation exports; eight exact excerpts from six sessions appear in the explainer.

### Supplied helpers

An author can inspect prior protocols, source receipts, original task contracts, four freeze manifests and retained verifier results. This is a source-study workflow, not a single solver packet.

### Callable tools

Read-only record search, hash checking and source inspection. Each historical prototype declares its own solver tools and environment. No new history search or trial is required by this explanation.

### Reference-only material

Author reference transcripts, controlled label edits, expected masks and private verifier reports. The explainer reveals recorded outcomes separately from the source records. Original solver/reference boundaries remain unchanged.

## Task specification

1. Retrieve bounded source records and retain exact role, location and hash.
2. Classify recovered user reports, assistant diagnoses, new proposals and unrecovered recollections.
3. State each candidate's given data, required output and independent reference; retain changes from the original crux.
4. Match frozen files and task checksums to separate oracle, no-op and model executions.
5. Interpret each original endpoint within scope and preserve untested candidates.

## Expected output

An auditable source screen linking eight excerpts to five candidates: table lineage, simulated chat recovery, annotation QA, patient-plane SVG and untested vector-crop ownership. The four executed contracts retain their individual results and controls.

## Evaluation

The new audit verifies 182 source pins, 76 frozen files, four archives and twelve raw results. Four Terra/high attempts pass their distinct endpoints: 4/4 table checks, 22/22 chat traces, 5/5 correlated QA packets and 12/12 SVG views with all 72 label Dice equal to one. Eight controls are separate executions. These are recorded outcomes, not new model trials.

## Difficulty

Authenticating a quotation does not validate its diagnosis. H01 fixed-document table curation does not answer H05 authentic vector-crop ownership. Exact recalled SVG and timeout/reroute incidents were not recovered. H03 is an explicit new proposal.

## Coverage

The native experiment index covers six medical executions; the full-round audit additionally covers the archived PDF/chat executions. Endpoints cannot be pooled; H03 and H04 share one CT. The historical study remains closed, with no clinical, population or runtime-recovery claim.
