# Retained dental pilot authoring scripts

These are the original one-off preparation, launcher, transport and scorer sources
for the completed F018 pilot. Their bytes are retained for provenance, including
original compact formatting; they are not a maintained rerun interface.

Do not import or execute `prepare.py` to inspect metadata: it performs writes at
module scope and can overwrite the original local task. Do not rerun `launch.py`
during cleanup. Frozen task packages, original attempt evidence and exact scorer
copies remain under their recorded local paths. A future experiment requires a
new task directory and separate authorization.

See the [protocol](../protocol.md) and [final finding](../../../findings/dental-ct-only-astra-medium.md).
