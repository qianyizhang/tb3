# Anatomical landmarks

Can agents locate named targets in native scans and recognize when targets are outside the field of view?

Preserve voxel/world coordinate contracts and all-visible-target denominators. Model/effort and atlas assistance are separate comparison variables.

Use `uv run med list --group anatomical-landmarks` from the repository root. The group owns the current research entry point; original protocols and frozen evidence remain at their recorded paths.
