# Lesion localization

Can agents identify and locate lesions while preserving negative controls and source-reference uncertainty?

Weak lesion regions support bounded localization checks, not exact clinical boundaries. Source-assisted negative answers remain a separate evidence condition.

Use `uv run med list --group lesion-localization` from the repository root. The group owns the current research entry point; original protocols and frozen evidence remain at their recorded paths.
