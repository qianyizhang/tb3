Why whole-mask Dice misses the problem

Most voxels never changed. The proposed mask already scores 99.845% whole-mask Dice, yet the tested right-Pcom route is broken. A different path can also keep the foreground globally connected. The verifier therefore restricts its connection check to a local vessel corridor and separately checks coverage, preserved branches, and collateral changes.

This is a local topology problem: “are these particular attachments connected along the intended route?” A whole-mask overlap score answers a different question.

What this example establishes—and its limits

Real TopCoW MRA, case 007, with a deliberately authored 1.8 mm-radius deletion in the right posterior communicating artery mask. The source image was unchanged. This was one successful calibration run, and a simple image-guided baseline also passed.

The solver was allowed to return the input unchanged. It saw the MRA, proposed binary mask, editable region, and geometry—not the class labels, reference mask, graph nodes, or evaluator. The final reference reveal is for the reader.

Observed image viewing and image-based code do not establish that images were necessary: no image-ablation experiment was run. A separate unchanged-mask case had an unresolved annotation disagreement; this successful repair does not resolve it. No general success rate, natural-error difficulty, or clinical correctness is claimed.
