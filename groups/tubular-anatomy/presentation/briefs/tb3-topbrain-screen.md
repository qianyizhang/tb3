# Screen TopBrain predictions for a repair task

**Author source study:** decide whether retained brain-vessel predictions provide
a defensible named-branch repair, routing or preservation task. Five predictions
were screened; no brain task or coding-agent trial was admitted.

## Value

Separates a real segmentation discrepancy from a suitable task. A geometric gap,
a disputed reference contact and an already-preserved variant need different
decisions before any agent can be scored fairly.

## Given

### Original data

Five public training/development MRA volumes: 004, 007, 012, then 006 and 011.
The last two were selected because reference labels identify third-A2/A3 variants.
Images use native LPS-oriented voxel axes and NIfTI RAS+ physical coordinates in mm.

### Supplied helpers

Untouched full-volume predictions from one official TA36 ResEncM fold-4 component,
plus the author-visible 36-class label map and reference volumes. No synthetic
defect was injected. References assist case selection and comparison; they do
not enter the retained segmentation inference. This is not a blind solver packet.

### Callable tools

The retained screen used scientific array, connectivity and image-viewing tools.
Released preprocessing and sliding-window prediction ran on MPS with Gaussian
blending and 0.5 tile step. This was one component, without the official ensemble
or component-pruning postprocessing. No new inference is implied here.

### Reference-only material

TA36 labels, label scores, reference parent components and the saved comparison
route are reader reveals. The author had access during curation. The teaching
HTML embeds them; it is unsuitable as a reference-hidden solver packet.

## Task specification

Find a natural class or connection error with enough proximal context to identify
the correct parent and named target. Exclude disputed references and crop artifacts;
retain parent-connected preservation controls. Compare ordinary geometric repair
before calling a case difficult. Freeze a task and independent verifier only if
a clean error/control set survives these checks.

## Expected output

A source-screening disposition with case IDs, provenance, candidate mechanism,
reference ambiguity and admission status. The retained author calibration also
has a full labeled NIfTI, 344-point RAS+ centerline, eight 344×51 CPR rasters with
source coordinates and signal values, and a BA-plus-R-SCA PLY mesh. These are
calibration outputs, not scored coding-agent submissions.

## Evaluation

Reproduced development label Dice, 6/26-neighbour contact counts, selected
parent-chain connectivity, and calibration preservation/source-sampling checks.
The geometry-only repair adds two voxels; one is reference R-SCA and one is
reference background. No accepted brain task, numeric agent pass gate or coding-agent
score exists. The airway trial in the same BR-033 record is a separate condition.

## Difficulty

The small R-SCA gap was geometrically repairable; three PCA–SCA contacts were
reference-convention ambiguous; two third-artery variants were already preserved.
This bounded screen left the named-branch repair hypothesis untested. It does
not establish held-out performance or intrinsic brain-vessel difficulty.

## Coverage

Five scans, one model component, 160 present-label comparisons and selected
source views. The 0.5 mm reference-interior screen can miss thin-vessel errors;
no exhaustive manual review or clinical adjudication occurred. Native sections
retain physical pixel spacing; projections collapse depth and cannot prove contact.
Source terms permit noncommercial use with attribution; commercial use needs
the data owner's permission.

## Cases

004 supplies the saved R-SCA gap calibration and a left PCA–SCA contact;
007 supplies a right contact and the reference L-MCA parent-chain concern;
011 supplies a left contact and a preserved third-A2/A3 variant. 006 supplies
the other preserved variant. 012 remains part of the five-scan source screen.
These selected views do not constitute exhaustive review of the volumes.

## Gaps

No clean hard brain task, independent frozen verifier or coding-agent result
was produced. Reference contacts and parent fragmentation remain unadjudicated;
neither establishes anatomical error. Reopening requires a substantial supported
natural error, reliable parent/target identity and intact or adjudicated absence
controls. The bounded screen does not rule out other useful TopBrain cases.
