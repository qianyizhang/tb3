01 / THE TASK

Discover the vessels.
Then decide what they are.

The agent starts from a full 3D CTA and a generic naming vocabulary. It must create its own views, identify candidate vessels, trace their courses and export named centerlines in physical coordinates.

No mask, seed point, endpoint, branch-presence list or previous solution is supplied. The image is 512 × 512 × 275 at 0.377 × 0.377 × 0.5 mm. The agent uses a CPU Python environment and writes its own classical image-processing pipeline.

Requested scope ≠ measured scope

The prompt asks for a broad vascular inventory. Automated scoring measures only the annotated coronary subset: 18 polylines · 11 categories · 646.24 mm.

More pulmonary vessels or veins can improve the requested deliverable without changing this score. Extra, unannotated output remains unadjudicated.

04 / METHODOLOGY

The agent builds a pipeline.
The pipeline preserves its decisions.

The repeated recipe is image inspection, tubular features, graph/path search, image-derived controls, local centering and anatomical review. The saved controls make extraction repeatable—but do not make blind discovery automatic.

05 / FAILURE MECHANISMS

Two missing branches.
Two different points of failure.

“More compute” repeats an error when the search and review process keeps the same filters and accepted hypotheses.

The candidate generator was independently reconstructed and exactly matched the saved candidate voxel set. Reference-assisted measurement then identifies where each branch is lost. Candidate coverage is diagnostic; unordered candidate points are not a submitted arterial reconstruction.

Same geometry, worse names

Missing earlier branches shifts downstream identities: most of reference Other becomes “D2”; the recovered OM2 becomes “OM1.” This converts a discovery problem into a second labeling problem.

D2 / ACCEPTANCE

Detected, reviewed, withheld.

87.8% of reference D2 survives the default candidate gates. The agent views the location but treats the structure as a possible atrial/myocardial ridge. Only 3.1% reaches the final geometry.

The missing step is supported arterial identity and connection—not simply stronger tube enhancement.

OM1 / FILTERING

Signal exists; the list drops it.

A 13-voxel fragment is 4.55 mm from an existing path and fails the 2.2 mm parent-gap cutoff. A smaller fragment fails the size gate. Neither reaches the accepted candidate list.

Lowering vesselness recovers raw signal but merges it into an oversized component, so OM1 is still rejected.

07 / REFERENCE LIMITS

There is a naming dispute.
It does not explain the whole plateau.

The frozen scorer reproduces exactly, and the reference scores 100% against itself. That establishes internal consistency, not anatomical truth.

The R-PDA disagreement affects approximately 2.17 percentage points of reference length. Even optimistically correcting every label on the existing final geometry leaves the category mean at 75.53%—below the 90% gate, with D2 and OM1 still nearly absent.

ImageCAS-X mask and centerline agreement is not independent adjudication: they share an annotation pipeline. Small-branch conventions and selected multiple PDA/PLA courses require careful interpretation. Clinical/reference disputes remain open pending appropriate review.

08 / WHAT THIS SUGGESTS

Change the discovery and review loop
before adding another long run.

01

Keep branch hypotheses alive

Persist accepted, rejected and uncertain candidates, with parent evidence. Revisit consequential rejections before expanding peripheral inventory.

02

Filter paths, not whole components

Decompose skeleton graphs into branches. Test bounded, image-supported reconnection instead of a single hard parent-distance gate.

03

Evaluate the full reasoning chain

Separate discovery, topology, geometry and identity. Adjudicate ambiguous labels; repeat a fixed protocol across cases and completed attempts.

These are assistant recommendations and testable hypotheses. No new model run or validated performance improvement is claimed.
