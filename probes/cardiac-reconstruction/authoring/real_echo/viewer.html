This case has no reference mesh or tissue tracking. Image agreement and a valid mesh cannot establish accurate 3D anatomy, myocardial strain, clinical EF or pathology. Public-source training exposure remains unknown.
Input-response finding: the saved script keeps the same pulse when all input frames are held still.

Replacing each supplied video with repetitions of its first image produced exactly the same vertex coordinates and alternatives. The script replays fixed visual measurements; it does not re-estimate geometry from new pixels. A separate coordinate-change check passed.

The mesh remains the submitted sequence. Withheld panels continue showing their original frames. This diagnoses the executable's input response; it is not a test for pretraining contamination.
