Both models failed with small patches; both passed with larger context. Separate translations at each landmark can represent nonrigid motion. A local affine patch model was unnecessary on this case.

This isolates context within the author pipeline. That pipeline also differs from the original agent's initialization and similarity metric, so this is not a one-line repair or proof that context alone explains the agent's miss.
