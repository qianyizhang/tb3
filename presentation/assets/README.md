# Reusable presentation assets

This is the home for authored teaching assets shared by browser presentations.
The [teaching library](teaching/README.md) contains task-specific SVG input/output
pictures and a catalogue of plain-language transformations. The Task Explorer
uses it for both persistent storyboards and its static fallback.

Source-derived teaching anatomy remains in
[task-explorer/anatomy](../task-explorer/anatomy/NOTICE.md), beside its hashes,
source attribution and licenses. Native dataset previews belong to the
[dataset preview register](../../datasets/README.md). This directory does not
turn a diagram into a dataset sample, a prediction or an evaluator reference.
